# Contributing to ocaml-hexaly

Thanks for your interest. This guide covers the layout, build modes, common
extension tasks, and CI considerations.

## Project layout

```
src/
├── dune                    Build rules for the library
├── config/
│   ├── dune                Executable rule for the configurator
│   └── discover.ml         Build-time probe (replaces configure.sh).
│                           Plain OCaml; no shell scripts.
├── hexaly.{ml,mli}         Public OCaml API
├── hexaly_stubs.c          OCaml C stubs (custom blocks + finalizers)
├── hexaly_shim.h           extern "C" surface
├── hexaly_shim_real.cpp    Real backend; links against libhexaly
├── hexaly_shim_mock.cpp    Mock backend; in-process brute force
└── hexaly_shim.cpp         GENERATED by discover.ml; #includes one of the above

test/                       Alcotest suite; runs against either backend
examples/                   knapsack, tsp, scheduling
bench/                      Benchmark for FFI overhead
.github/workflows/ci.yml    Mock-backend matrix on macOS + Linux
.github/workflows/docs.yml  Builds odoc and deploys it to GitHub Pages
```

## Build modes

### Mock backend (no Hexaly needed)

```sh
export HEXALY_BACKEND=mock
dune clean && dune build
dune runtest
```

The mock implements a brute-force solver (≤ 2^20 assignments). It's used
for CI and for hacking on the OCaml/C-stubs layers without a license.

### Real backend

```sh
export HEXALY_HOME=/opt/hexaly_14_5            # or wherever installed
export HX_LICENSE_PATH=/path/to/license.dat
export HEXALY_BACKEND=real
dune clean && dune build
dune runtest
```

`src/config/discover.ml` auto-detects the backend if `HEXALY_BACKEND` is unset.

## Adding a new C++ method

The binding has four mirrored layers. Update them in this order:

1. **`src/hexaly_shim.h`**: add an `extern "C"` entry-point declaration.
2. **`src/hexaly_shim_real.cpp`**: implement using the C++ class. Wrap
   the body in `HXS_TRY ... HXS_CATCH_*`; never let a C++ exception
   escape into OCaml.
3. **`src/hexaly_shim_mock.cpp`**: implement a reasonable stub so the
   mock backend stays in sync. If a real-Hexaly-only semantic is hard to
   mock, return a benign default and add `if (is_mock ())
   Alcotest.skip ()` in the relevant test.
4. **`src/hexaly_stubs.c`**: add an OCaml C stub using `CAMLparam*` /
   `CAMLreturn` and the `*_get` accessors.
5. **`src/hexaly.ml`** + **`src/hexaly.mli`**: declare the `external`
   binding and the friendly OCaml wrapper. Document it in the `.mli`.

When you add an op:
- Update `hxs_operator` in `hexaly_shim.h` (matching `HxOperator` declaration
  order in `$HEXALY_HOME/include/optimizer/hxoperator.h`)
- Add a `static_assert` in `hexaly_shim_real.cpp` (the compile fails loudly
  if you got the position wrong)
- Update `Op.t` and `Op.to_int` in `hexaly.ml`

## Hexaly version drift

The `static_asserts` in `hexaly_shim_real.cpp` catch most enum drift at
compile time. If a new Hexaly minor version shuffles `HxOperator` order,
those asserts will fire; regenerate `hxs_operator` from
`$HEXALY_HOME/include/optimizer/hxoperator.h` and update `Op.to_int`
in `hexaly.ml`.

For error codes, callback types, and state, the same pattern applies
(asserts in `hexaly_shim_real.cpp`).

## Tests

Use alcotest:

```ocaml
let test_my_feature () =
  let o = mk_opt () in
  ...
  Alcotest.(check int) "...what..." expected actual

let () = Alcotest.run "hexaly" [
  "my_group", [
    Alcotest.test_case "my_feature" `Quick test_my_feature;
  ];
  ...
]
```

If a test only makes sense against real Hexaly, skip it cleanly on mock:

```ocaml
let test_routing () =
  if Sys.getenv_opt "HEXALY_BACKEND" = Some "mock" then Alcotest.skip () else
  ...
```

## Real-backend CI

Public CI can only run the mock backend, because Hexaly is proprietary and
licensed per machine. To run real-backend tests:

1. Provision a self-hosted runner with Hexaly installed and a license
   file mounted as `/var/run/secrets/hexaly_license.dat`.
2. Add a job to `.github/workflows/ci.yml` with
   `runs-on: [self-hosted, hexaly]` and `HX_LICENSE_PATH=/var/run/secrets/hexaly_license.dat`.
3. Run `HEXALY_BACKEND=real dune runtest` in that job.

## Commit messages

We follow [Conventional Commits](https://www.conventionalcommits.org/):
```
feat: add multi-objective phase API
fix(stubs): release runtime lock around solve()
docs: clarify warm-start semantics
test: cover interval-var with optional presence
```

## Reporting issues

When filing a bug, please include:
- Hexaly version (`Hexaly.Version.string ()`)
- OCaml version (`ocaml --version`)
- Backend (real or mock)
- Minimal failing program
- Stack trace if it's a crash
